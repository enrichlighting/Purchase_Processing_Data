โฟลเดอร์นี้เก็บไฟล์บันทึกการจัด Packing List จากหน้าเว็บ stock-analysis.html

วิธีให้ไฟล์มาลงที่นี่อัตโนมัติ:
1) เปิด stock-analysis.html → แท็บ "Packing List"
2) กดปุ่ม "📁 ตั้งโฟลเดอร์บันทึก" แล้วเลือกโฟลเดอร์นี้ (Packing list log) — ทำครั้งเดียว
   (รองรับ Chrome / Edge ; ถ้าเบราว์เซอร์ไม่รองรับ ไฟล์จะดาวน์โหลดลงโฟลเดอร์ Downloads แทน)
3) จัดสินค้าลงตู้ตามต้องการ แล้วกด "💾 บันทึกรอบนี้"

แต่ละรอบที่บันทึกจะได้ 2 ไฟล์ (ชื่อไฟล์มี วัน-เวลา ที่บันทึก):
- PackingList_YYYY-MM-DD_HHMMSS.xls  → ตารางลิสท์ (จำนวนชิ้น/Lot ต่อตู้ · กล่อง · CBM · มูลค่า)
- Containers_YYYY-MM-DD_HHMMSS.png   → ภาพตู้จำลองของรอบนั้น

ประวัติการบันทึกทั้งหมดจะแสดงในตาราง "🗂️ ประวัติการบันทึก Packing List" ท้ายหน้า
และเก็บอยู่ในเบราว์เซอร์ (สามารถกด "โหลดกลับ" เพื่อเรียกการจัดตู้รอบเก่ากลับมาแก้ไขได้)
